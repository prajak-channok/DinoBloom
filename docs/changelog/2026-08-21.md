## Spawn Pacing — แยกตาม Wave
- `spawn_manager.start_wave()` รับพารามิเตอร์ `is_first_wave` เพิ่ม (ส่งมาจาก `match_manager._begin_playing()` ด้วย `current_wave == 1`)
- **Wave 1 ของทุกด่าน**: ใช้ pacing เดิมทั้งหมด (ไม่เปลี่ยน)
- **Wave 2 เป็นต้นไปของทุกด่าน**: สุ่มช่วงเวลาระหว่างการ Spawn แต่ละตัวที่ 0.5–3.0 วินาที (`randf_range(0.5, 3.0)`) ตลอดทั้ง Wave ไม่มี phase พิเศษ 15 วินาทีแรกแบบ Wave 1 — เป็น pacing ที่ตั้งใจไว้ ยังมีผลอยู่ปัจจุบัน (ดู `04_CURRENT_STATUS.md`)

## Bug Fix — ไดโนเสาร์ถูก "ดันออก" ทันทีเมื่อวางพืชทับตำแหน่งที่กำลังยืนกิน
- Root cause: `dryosaurus.gd` / `velociraptor.gd` / `triceratops.gd` / `trex.gd` ใน `_process()` มี logic ร่วมกัน (copy-paste) ที่ force `position.x = stop_x` ทุกครั้งที่ `position.x < stop_x` ในสาขา eating ปกติ ตอนเดินเข้าใกล้พืชแบบต่อเนื่อง สาขา walking จะ clamp ด้วย `maxf(...)` ให้ตัวไปหยุดที่ `stop_x` พอดีอยู่แล้ว (บรรทัดนี้เป็น no-op) แต่พอผู้เล่นวางพืชใหม่ทับ/หลังตำแหน่งที่ไดโนเสาร์ยืนอยู่ (ยังอยู่ในระยะตรวจจับของ `_find_next_plant_ahead()`) ค่า `stop_x` ที่คำนวณใหม่จะมากกว่า `position.x` ปัจจุบันทันที ทำให้บรรทัดนี้ teleport ตัวไดโนเสาร์ไปข้างหน้า (ไปทางขวา) แบบไม่ต่อเนื่อง กลายเป็นอาการ "ดันออก"
- แก้โดยลบบรรทัด snap (`if position.x < stop_x: position.x = stop_x`) ออกจากทั้ง 4 ไฟล์ — ถ้าเข้าสาขา eating แบบ `position.x <= stop_x` แล้ว ให้กินอยู่ตรงตำแหน่งปัจจุบันเลย ไม่ขยับ ส่วนสาขา walking (การเดินเข้าใกล้ตามปกติ) ไม่กระทบเพราะยังใช้ `maxf(...)` clamp เหมือนเดิม
- Verified: Headless Parser Check + Runtime Check (`gameplay_scene.tscn`, `scenes/enemies/trex.tscn`) ไม่มี Error ใหม่
